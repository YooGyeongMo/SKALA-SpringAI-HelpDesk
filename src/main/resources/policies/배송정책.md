# SKALA 쇼핑몰 배송 정책

문서 버전: 2026-07 | 담당 부서: 물류

## 1. 배송 기간

- 기본 배송: 결제 완료 후 **2~3 영업일** 내 도착
- 새벽 배송: 전날 23시 이전 주문 시 다음 날 오전 7시 전 도착 (수도권 한정)
- 도서·산간 지역: 기본 배송 + 1~2일 추가, 추가 배송비 3,000원

## 2. 배송 상태 안내

| 상태 | 의미 |
|---|---|
| PAID | 결제 완료 |
| PREPARING | 상품 준비중 |
| SHIPPING | 배송중 — 이 단계부터 주문 취소 불가, 교환·환불은 배송 완료 후 접수 |
| DELIVERED | 배송 완료 — 이 시점부터 반품·교환 신청 기간(7일)이 시작된다 |

## 3. 배송 조회

주문번호로 HelpDesk에서 실시간 배송 상태와 예상 도착일을 조회할 수 있다. 송장 번호는 발송 시점에 문자로 안내된다.

## 4. 배송 지연

천재지변·물량 급증으로 배송이 지연될 수 있으며, 3영업일 이상 지연 시 보상 포인트(주문 금액의 2%)가 자동 지급된다.

## 5. 배송지 변경

**상품 준비중(PREPARING) 상태까지만** 배송지 변경이 가능하다. 배송중(SHIPPING) 이후에는 택배사 사정에 따라 불가할 수 있다.
