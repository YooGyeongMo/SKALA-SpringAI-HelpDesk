# SKALA 쇼핑몰 회원 등급·혜택

문서 버전: 2026-07 | 담당 부서: CRM

## 1. 등급 기준 (최근 6개월 구매 금액)

| 등급 | 기준 | 주요 혜택 |
|---|---|---|
| SILVER | 가입 시 기본 | 구매 적립 1% |
| GOLD | 30만원 이상 | 적립 2% + 무료배송 쿠폰 월 2장 |
| VIP | 100만원 이상 | 적립 3% + 무료배송 무제한 + **단순 변심 반품 배송비 월 2회 면제** |

## 2. 등급 산정 주기

매월 1일에 직전 6개월 구매 확정 금액으로 재산정된다. 반품·취소 금액은 산정에서 제외된다.

## 3. 포인트

- 적립 포인트는 적립일로부터 **1년** 후 소멸된다.
- 1,000포인트 이상부터 현금처럼 사용 가능하다.
- 반품 시 사용 포인트는 즉시 재적립된다.

## 4. 생일 혜택

생일 월에 10% 할인 쿠폰(최대 2만원)이 자동 발급된다. 유효기간은 발급일로부터 30일이다.
